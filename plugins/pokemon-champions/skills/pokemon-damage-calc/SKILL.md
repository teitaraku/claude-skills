# ポケモンチャンピオンズ ダメージ計算 Skill

## ダメージ計算式（Lv.50固定）

```
基本ダメージ = (((2×Lv÷5 + 2) × 技威力 × A÷D) ÷ 50 + 2)
            = (((22) × 技威力 × A÷D) ÷ 50 + 2)   ※Lv50固定なので係数22

最終ダメージ = 基本ダメージ × 各種補正（順次乗算、各段階で小数点以下切り捨て）
```

- **A**: 攻撃側の こうげき or とくこう の実数値（物理/特殊で変わる）
- **D**: 防御側の ぼうぎょ or とくぼう の実数値

## 主要な補正一覧（乗算順）

| 補正項目 | 倍率 | 備考 |
|---|---|---|
| 天候補正 | ×1.5 / ×0.5 | 晴れで炎1.5倍・水0.5倍、雨で水1.5倍・炎0.5倍 |
| 急所 | ×1.5 | 急所時。防御側の能力上昇・攻撃側の能力下降を無視 |
| 乱数 | ×0.85〜1.00 | 16段階（85, 86, …, 100/100）の一様乱数 |
| タイプ一致（STAB） | ×1.5 | 攻撃側と同じタイプの技。**てきおうりょく**なら ×2.0 |
| タイプ相性 | ×0.25 / ×0.5 / ×1 / ×2 / ×4 | タイプ相性表を参照（`../pokemon-party-builder/references/type-chart.md`）。×0なら無効 |
| やけど | ×0.5 | 物理技のみ。とくせい「こんじょう」は無効 |
| 持ち物（タイプ強化） | ×1.2 | もくたん／じしゃく等。本作の火力アイテムの主役 |
| 持ち物（でんきだま） | ×2.0 | ピカチュウ専用、攻撃・特攻が2倍 |
| とくせい補正 | 各種 | テクニシャン×1.5（威力60以下）、すなのちから×1.3（砂下・岩/地/鋼）等 |
| 壁（リフレクター/ひかりのかべ） | ×0.5（シングル）／×0.66（ダブル） | 急所時は無視 |
| ばつぐん補正（とくせい） | ×0.75 | 「ハードロック」「フィルター」 |

## 計算順序（標準）

```
1. 基本ダメージを算出
2. ×天候補正
3. ×急所補正
4. ×乱数（85〜100%）
5. ×タイプ一致（STAB / てきおうりょく）
6. ×タイプ相性
7. ×やけど（物理のみ）
8. ×その他補正（壁・持ち物・とくせい等）
```

## ステータス計算式（実数値を求める場合）

```
HP以外: {(種族値×2 + 31 + 能力ポイント×2) × 50 ÷ 100 + 5} × 性格補正（小数点以下切捨て）
HP:      (種族値×2 + 31 + 能力ポイント×2) × 50 ÷ 100 + 60
```

能力ポイントは「実数値に直接加算」されるため、性格補正なしの場合 **1ポイント = 実数値+1**。

## 確定数の判定手順

1. 攻撃側・防御側の実数値を上の計算式で算出
2. 基本ダメージを算出
3. 補正を順次乗算（各段階で小数点以下切り捨て）
4. 乱数最小（×0.85）と最大（×1.00）の両方を計算
5. 防御側 HP に対して何発必要か判定

### 計算例

> 攻撃180のメガガブリアスのげきりん（威力120、ドラゴン技・タイプ一致）が、HP175・防御120のカイリュー（ドラゴン2倍弱点）に当たる場合

```
基本ダメージ = (22 × 120 × 180 ÷ 120) ÷ 50 + 2 = 81
最終（乱数最小） = 81 × 1.5（STAB） × 2.0（2倍弱点） × 0.85 = 205
最終（乱数最大） = 81 × 1.5 × 2.0 × 1.00 = 242
```

HP175に対して205〜242 → **確定1発**。

## 本作で特に意識すべきポイント

- **こだわりメガネ・いのちのたまが未実装**のため、火力補正の上限は「タイプ強化系の×1.2」が標準
- そのため過去作より**全体的にダメージが伸びにくく**、耐久ラインの調整が刺さりやすい
- **急所率アップ持ち（ピントレンズ）+ きあいだめ**で確定急所×1.5を狙う戦法が相対的に強い
- 能力ポイントが直接実数値に加算される仕様上、**1ポイントの調整が確定数を変える**ことがあるため、計算式に基づいた緻密な調整が重要

## ダメージ計算の質問時の対応手順

1. 攻撃側・防御側のポケモン名と技名を確認
2. 能力ポイントの振り方（わからなければ典型的な振り方を仮定して明示）
3. 性格・特性・持ち物・天候・壁の有無を確認
4. 実数値を計算し、ダメージ範囲と確定数を提示
5. 確定数を変えるための調整案があれば提案する
