# ポケモンチャンピオンズ パーティ構築 Skill

## ゲーム概要

**Pokémon Champions（ポケモンチャンピオンズ）** は2026年4月8日にNintendo Switch向けにリリースされたポケモンバトル特化の新作タイトル（基本無料）。スマホ版は2026年夏予定。ポケモンHOMEとの連携により歴代シリーズのポケモンを「遠征」させることができる。

---

## 参照リソース

レギュレーション・タイプ相性・役割別ポケモン・データシートの詳細は必ず以下を参照すること。
種族値・タイプ・特性・持ち物効果・対戦時間など、正確な値が必要な情報は **`references/data/*.json` を正本** とし、Markdown は解説・候補整理として使う。

- **`references/data/pokemon.json`**: Regulation M-A の使用可能ポケモン・フォーム一覧、タイプ、種族値、特性、メガストーン。`verification_status` が `needs_confirmation` の値は断定しない
- **`references/data/items.json`**: 使用可能/未実装の持ち物、効果、入手方法
- **`references/data/regulations.json`**: レギュレーション期間、対戦時間、選出数、参照元
- **`references/regulation-ma.md`**: レギュレーションM-A（現行）の概要、使用可能ポケモン抜粋、メガシンカ候補、持ち物メモ、禁止事項
- **`references/type-chart.md`**: 18タイプの相性表、主要複合タイプの弱点早見表、「一貫」を避ける考え方
- **`references/role-pokemon.md`**: メガエース／展開役／受け／崩し／対面エース／サポート／ダブル特化 等、役割別の代表ポケモンプール
- **`references/pokemon-datasheet.md`**: 主要ポケモンの種族値・特性・テンプレ技・典型能力ポイント・素早さベンチマーク

### 参照ファイルの使い分け

| 場面 | 参照すべきファイル |
|------|---------------------|
| 種族値・タイプ・特性を確認したい | `data/pokemon.json` |
| 持ち物の使用可否を確認したい | `data/items.json` |
| レギュレーション期間・対戦時間を確認したい | `data/regulations.json` |
| 使ってよいか確認したい | `data/regulations.json` と `regulation-ma.md` |
| 弱点・耐性を確認したい | `type-chart.md` |
| 空いた役割を埋めたい | `role-pokemon.md` |
| 技構成・努力値を決めたい | `pokemon-datasheet.md` |

## バトル形式（共通仕様）

### シングルバトル
- パーティ6匹から**3匹**を選出して1vs1で対戦
- プレイヤー人口が多く、熾烈な順位争い

### ダブルバトル
- パーティ6匹から**4匹**を選出して2vs2で対戦
- 世界大会（WCS）でも採用される、戦略性の高いバトル形式

### 対戦時間（全レギュレーション共通）

| 項目 | 時間 |
|------|------|
| 持ち時間 | 10分 |
| 1ターン選択時間 | 60秒 |
| 選出時間 | 90秒 |

> 対戦時間は `references/data/regulations.json` を正本とする。外部情報やゲーム内表示で変更が確認された場合は JSON を更新する。

## 能力ポイント（旧：努力値）システム

本作で新しく導入されたチャンピオンズ固有の仕様。

### 過去作との比較

| 項目 | 従来作（SV等） | ポケモンチャンピオンズ |
|------|--------------|---------------------|
| 名称 | 努力値（きそポイント） | **能力ポイント**（Stat Points） |
| 最大合計 | 510 | **66** |
| 1ステータスの上限 | 252 | **32** |
| 実数値への効果 | 努力値252 → +32 | **能力ポイント32 → +32**（直接加算） |
| 個体値 | 0〜31でランダム | **31固定** |
| 表示 | 隠しパラメータ | **オープンな数値として表示** |
| コスト | アイテム（きょうせいギプス等） | **VP（1ポイント5VP）** |

### ステータス計算式（Lv.50固定）

```
HP以外: {(種族値×2 + 31 + 能力ポイント×2) × 50 ÷ 100 + 5} × 性格補正（小数点以下切捨て）
HP:      (種族値×2 + 31 + 能力ポイント×2) × 50 ÷ 100 + 60
```

能力ポイントは「実数値に直接加算」されるため、性格補正なしの場合 **1ポイント = 実数値+1** と直感的。

> ダメージ計算・確定数の詳細は `pokemon-damage-calc` スキルを参照。

### 基本の振り方

```
2ステ全振り: 32 + 32 = 64（残り2ポイントをほかのステータスに振れる）
```

過去作では252+252+4（端数6余り）だったが、チャンピオンズでは32+32+2と**端数なく使いきれる**。全体の合計能力値は過去作より+1大きくなる。

### よくある振り方パターン

| パターン | 振り方 | 向いているポケモン |
|----------|--------|--------------------|
| 2ステ全振り | 32-32-2 | 物理/特殊アタッカー（攻撃+素早さ など） |
| 耐久特化 | 32-32-2 | HP+防御 or HP+特防 |
| 調整振り | 任意 | 素早さラインや耐久ラインを特定値に合わせたいとき |

### 実践的な調整例

- **カイリュー（性格補正なし）**: 素早さに27振り → りゅうのまい1積みで最速ガブリアスを上回る
- **メガバンギラス**: 素早さに23振り → りゅうのまい1積みで最速ガブリアスを上回る
- **HPを奇数に調整**: ステルスロックの定数ダメージ軽減・みがわりの使用回数増加

> 素早さの主要ベンチマークは `references/pokemon-datasheet.md` の末尾を参照。

### リセット・変更

- ポイントを**減らすだけなら無料**
- 振り直しは1ポイントごとに5VP
- **トレーニングチケット**を使えばVP消費なしで変更可能
- HOMEから遠征させたポケモンは元ソフトの努力値を引き継ぐ。ただし**一度チャンピオンズに来た後は元ソフトで変更しても反映されない**（チャンピオンズ側でトレーニングすること）

## パーティ構築のフレームワーク

### ステップ1: コンセプト決定
1. シングル or ダブルを選択
2. メガエースを決める（パーティの核） → `role-pokemon.md` の「1. メガエース候補」を参照
3. プレイスタイル（攻め / 受け / バランス）

### ステップ2: 役割分担

`role-pokemon.md` の「役割テンプレート」を参考に、シングルなら6枠、ダブルなら6枠を埋めていく。

### ステップ3: タイプバランス

- `type-chart.md` で弱点を補い合える組み合わせを意識する
- 特定タイプへの**一貫**（複数匹が同じ弱点を持つこと）を避ける
- 環境で多い攻撃タイプ（じめん／ドラゴン／フェアリー／ほのお）は3匹以上が弱点にならないよう調整

### ステップ4: 持ち物の分配

- 同一持ち物は**2匹以上に持たせられない**ため分散が必須
- メガ枠にはメガストーンを持たせる（それ以外の持ち物は持たせられない）
- 使用可能な持ち物は `regulation-ma.md` を参照（こだわりメガネ／いのちのたま等は未実装）

### ステップ5: 技構成・能力ポイント

- 各ポケモンのテンプレ技は `pokemon-datasheet.md` を参照
- 素早さラインは「相手の○○抜き」を基準に振る
- 余ったポイントはHP・特防・防御に回すのが基本

## パーティ構築の質問時の対応手順

1. **シングル/ダブル**を確認
2. **使いたいポケモン・コンセプト**を確認（なければ聞く）
3. `references/regulation-ma.md` で**使用可否・メガ枠・持ち物**を確認
4. `references/role-pokemon.md` から**残り枠の候補プール**を提示し、相談しながら絞り込む
5. `references/type-chart.md` で**タイプ一貫チェック**（3匹以上が同じ弱点を共有していないか）
6. `references/data/pokemon.json` と `references/pokemon-datasheet.md` を参照し、**特性・技・能力ポイント**を埋める。JSON 側が `needs_confirmation` の情報は、未確認であることを明示する
7. **レギュレーションM-A適合チェック**（禁止ポケモン・禁止持ち物・持ち物重複がないか）
8. 下記フォーマットでパーティを出力する

## パーティ出力フォーマット

6匹それぞれについて以下の項目を必ず含めること：

```
## [ポケモン名]（メガシンカする場合はメガ後の名前も併記）

- 役割: （例: メガエース、ステルスロック展開、対面エース 等）
- 性格: （例: ようき、おくびょう 等）
- 特性: （例: すながくれ、せいしんりょく 等。メガシンカ後に特性が変わる場合は両方記載）
- 持ち物: （例: ガブリアスナイト、こだわりスカーフ 等）
- 能力ポイント: HP xx / こうげき xx / ぼうぎょ xx / とくこう xx / とくぼう xx / すばやさ xx（合計66）
- 技構成:
  1. 技名
  2. 技名
  3. 技名
  4. 技名
- 解説: この枠の採用理由・立ち回り・調整意図を簡潔に説明
```

最後に、6匹全体について：

```
## パーティ全体のコンセプト
（攻め/受け/バランス、メガエースを通すための立ち回り、選出パターン）

## 弱点一貫チェック
（環境上位タイプに対しての一貫を確認、弱点を共有する匹数）

## 想定される苦手構築と対策
（不利対面・苦手構築への対処方針）
```

### 出力時の注意点

- 能力ポイントの合計は必ず**66以下**になるよう確認する
- 1ステータスの上限は**32**
- 同じ持ち物が2匹以上にないか最終チェックする
- メガシンカ枠の持ち物は必ずメガストーンにする
- 未実装持ち物（こだわりメガネ、いのちのたま、ゴツゴツメット 等）を採用しない
- ダブル提案時はワイドガード／ファストガード／てだすけ／おいかぜ等のサポート技を意識する
