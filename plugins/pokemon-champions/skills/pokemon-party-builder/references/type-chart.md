## 環境で意識すべきタイプポイント

### 半減できると優秀なタイプ
- **じめん**: ガブリアス・ドリュウズ・ボスゴドラ等の高火力地震を耐える役は重要
- **フェアリー**: 環境にドラゴン（カイリュー、メガガブリアス）が多いため、フェアリー対策技も必須
- **ほのお**: メガリザ・メガヘルガー・シャンデラ等が環境にいる

### 環境で多い攻撃タイプ Top
1. **じめん**（地震）: 物理アタッカーの汎用打点
2. **ドラゴン**（げきりん、りゅうせいぐん）: ドラゴン枠の主要打点
3. **フェアリー**（ムーンフォース、じゃれつく）: ドラゴン対策
4. **ほのお**: メガリザY軸が顕著
5. **エスパー / ゴースト**: 高速アタッカーの主要打点

### 等倍以下に抑えやすい優秀タイプ
- **はがね**: 弱点3つ（炎・闘・地）と少ない。耐性多数
- **フェアリー**: ドラゴン無効・闘悪虫半減
- **みず**: 環境上位の炎・氷・鋼に強く出やすい

## 「一貫」を避ける構築の考え方

「一貫している」とは、**パーティの複数匹が同じタイプの技で大ダメージを受ける状態**。たとえばパーティに地面弱点が4匹いると、相手のガブリアス1匹で全滅級の被害が出る。

### チェックの仕方
1. 6匹それぞれが「2倍以上ダメージを受けるタイプ」をリストアップ
2. 同じタイプを弱点とする匹数を数える
3. 3匹以上で同じ弱点を共有していたら**要再考**（特に攻撃タイプとして環境に多いタイプは2匹以下にしたい）

### 補完の典型例
- 地面が一貫しがち → 飛行/浮遊持ち（カイリュー、ロトムフォルム、エアームド）を採用
- 氷が一貫しがち → 鋼タイプ（ハッサム、ナットレイ、ハガネール）を採用
- フェアリーが一貫しがち → 毒/鋼タイプ（キラフロル、ハッサム）を採用
