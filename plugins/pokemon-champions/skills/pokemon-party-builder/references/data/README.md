# 構造化データ

このディレクトリは、ポケモンチャンピオンズ関連スキルが参照する数値・ルール情報の正本を置く場所です。

## 方針

- 種族値、タイプ、特性、持ち物効果、レギュレーション期間など、正確性が必要な値は JSON を優先する。
- Markdown のリファレンスは構築方針・候補整理・読みやすい解説に使う。
- 未確認または過去作準拠の値は `verification_status` で明示し、断定しない。
- 新しい公式情報や主要データベースで確認したら、`verified_at` と `source_refs` を更新する。

## ファイル

| ファイル | 内容 |
|---|---|
| `pokemon.json` | Regulation M-A の使用可能ポケモン・フォーム一覧、タイプ、種族値、特性、メガストーン |
| `items.json` | 使用可能/未実装の持ち物、効果、入手方法 |
| `regulations.json` | レギュレーションM-Aの期間、対戦時間、メガシンカ候補、参照元 |

## `verification_status`

| 値 | 意味 |
|---|---|
| `confirmed_external` | 公式または主要データベースで確認済み |
| `legacy_reference` | 過去作の既知データに基づく。本作で変更があれば更新が必要 |
| `needs_confirmation` | 参戦・仕様・数値の確認が必要 |
