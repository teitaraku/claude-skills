# 主要ポケモン データシート リファレンス

レギュレーションM-Aの環境で採用率が高い／高くなることが見込まれる主要ポケモンのデータシート。
種族値・タイプ・特性候補・テンプレ技構成・典型持ち物・典型努力値（能力ポイント）パターンを記載する。

> 数値は過去作（Sword/Shield, Scarlet/Violet）の種族値に準拠。本作の仕様変更で数値が変更された場合は最新情報を優先すること。
> 能力ポイントは「HP/攻/防/特攻/特防/素早」の順、合計66以内、各上限32。

## データシートの読み方

1. **タイプと種族値**: パーティ内でのタイプ補完と素早さ調整の基準
2. **特性**: メガ前後で変わるケースに注意（特にすなおこし、ひでり、トレース等の場展開系）
3. **テンプレ技**: あくまで「定番」。環境や役割に応じて変更可
4. **典型能力ポイント**: 合計66以内・各上限32。素早さラインは環境のメタに応じて調整
5. **持ち物**: `regulation-ma.md` の未実装アイテムリストと必ず照合（こだわりメガネ、いのちのたま等は不可）
