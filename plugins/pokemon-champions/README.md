# Pokémon Champions

ポケモンチャンピオンズ（Pokémon Champions）のパーティ構築・ダメージ計算を支援する Claude Code スキルです。

## 機能

- 各レギュレーションに対応したパーティ提案（シングル・ダブル両対応）
- タイプ相性チェックと一貫対策
- 能力ポイント（Stat Points）の調整アドバイス
- メガシンカ枠・持ち物の選定（重複チェック含む）
- 役割別ポケモン候補の提示

## インストール

```
/plugin install pokemon-champions@teitaraku
```

## 使い方

ポケモンチャンピオンズのパーティ・構築・編成・対戦について質問すると、このスキルが自動的に起動します。

### 例

```
カイリューを軸にシングルのパーティを組んでほしい
このパーティのタイプ一貫を確認して
レギュレーションM-Aで使えるメガシンカポケモンを教えて
メガガブリアスの能力ポイントの振り方を提案して
```

## 収録データ

| ファイル | 内容 |
|----------|------|
| `references/regulation-ma.md` | レギュレーションM-A（使用可能ポケモン・メガシンカ・持ち物一覧） |
| `references/type-chart.md` | 18タイプの相性表・複合タイプ弱点早見表 |
| `references/role-pokemon.md` | 役割別ポケモンプール（メガエース・展開役・受け・崩し 等） |
| `references/pokemon-datasheet.md` | 主要ポケモンの種族値・特性・技構成・素早さベンチマーク |

## 出力フォーマット

パーティを提案する際は以下を含めて出力します：

- 各ポケモンの役割・性格・特性・持ち物
- 能力ポイント配分（合計66以下）
- 技構成と採用理由
- パーティ全体のコンセプト・弱点一貫チェック・苦手構築への対策
